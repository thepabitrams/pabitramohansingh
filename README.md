# Pabitra Portfolio

My personal portfolio built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).  
Showcases my projects, skills, and blog posts.

## Features

- 🚀 Blazing fast static site with Astro
- 🎨 Utility‑first styling with Tailwind CSS
- 📝 MDX support for writing blog posts
- ⚡️ TypeScript for type safety
- 📱 Fully responsive
